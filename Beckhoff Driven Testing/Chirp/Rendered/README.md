# Rendered Chirp Run

Generated by `../render_chirp_sequence.py` from the same constants used by the Beckhoff ST test.

- `chirp_sequence_overview.png` — complete 207 s run: settle, 250→1000 Hz, settle, 1000→250 Hz, settle.
- `chirp_sampling_detail.png` — cyclic 250 µs commands compared with the analytic waveform at 250 Hz and 1 kHz.

Regenerate from the `Chirp` folder with:

```powershell
$env:MPLBACKEND='Agg'
python .\render_chirp_sequence.py
```
