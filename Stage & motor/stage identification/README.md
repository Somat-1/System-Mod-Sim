# Stage identification

Stage-identification work is grouped by the effect being identified:

```text
stage identification/
├── Geometric Fitting/                 geometric error identification and compensation
└── Friction Identification/
    └── Preliminary/                   the existing exploratory friction-related campaigns
```

- [`Geometric Fitting/`](Geometric%20Fitting/) contains the geometric fitting work.
- [`Friction Identification/`](Friction%20Identification/) contains the friction
  identification work. Its current material is preliminary and is grouped without
  implying that the campaign design or results are final.
